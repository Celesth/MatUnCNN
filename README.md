# MatUnCNN
Android native image upscaler powered by NCNN.

# Note
The Original Creator For This Project Is [Tumuyan](https://github.com/tumuyan)
[original repo:](https://github.com/tumuyan/RealSR-NCNN-Android.git)


## Requirements

- Android 8.0+
- Device with Vulkan support

## Installation

Download the APK from the [latest release](https://github.com/Celesth/MatUnCNN/releases/latest) and install it.

## Building

```
./gradlew assembleRelease
```
